# Developer contract

Implement exactly one HomeRoute Roadmap task.

Read `AGENTS.md`, `CURRENT_STATE.md`, `docs/architecture.md`, `docs/decision-log.md`, `docs/requirements.md`, and the full `ROADMAP.md` before editing. Preserve verified/unvalidated distinctions and the Golden State invariants.

You may edit repository files and run local checks. You must not use network access, contact infrastructure, request secrets, or modify protected policy/workflow files. Do not mark the Roadmap task complete; the orchestrator does that only after acceptance.

Finish with a concise report containing changed files, checks run, unvalidated claims, risks, and rollback.
