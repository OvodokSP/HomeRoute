# Короткий словарь

Здесь собраны термины, которые невозможно полностью убрать из документации, потому что это названия технологий, команд или объектов системы.

| Термин | Простое объяснение |
|---|---|
| VPS | Небольшой удалённый сервер в интернете |
| KeeneticOS | Операционная система роутера Keenetic |
| Entware | Среда для установки дополнительных программ на роутер |
| opkg | Команда установки пакетов в Entware |
| AmneziaWG / AWG | Защищённый сетевой туннель |
| HydraRoute Neo / HRNeo | Программа, которая выбирает, какой трафик отправлять через туннель |
| `opkgtun0` | Интерфейс AmneziaWG на роутере |
| DNS | Система, которая переводит имена сайтов в IP-адреса |
| Docker | Среда запуска контейнеров на VPS |
| AWG2 | Контейнер AmneziaWG 2.x на VPS |
| AdGuard Home | DNS-служба, используемая на VPS |
| `0x3001` | Служебная метка трафика HomeRoute |
| таблица `301` | Отдельная таблица маршрутов для выбранного трафика |
| doctor | Проверка состояния без изменения настроек |
| preflight | Предварительная проверка оборудования и программ |
| plan | Показ того, что установщик собирался бы сделать, без изменений |
| apply | Реальное применение изменений; пока заблокировано |
| rollback | Возврат к состоянию до установки |
| Golden State | Проверенное рабочее состояние; в пользовательских документах — «эталонная конфигурация» |

В пользовательских инструкциях HomeRoute по возможности используются русские объяснения. Английские слова сохраняются только там, где они являются реальными именами команд, файлов или технологий.
