# Как выглядит развёртывание

Эта страница показывает общий порядок действий без лишних технических деталей.

## Если у вас Keenetic

Перепрошивка не нужна.

Порядок такой:

1. убедиться, что модель подходит;
2. установить и проверить Entware;
3. проверить свободную память и место;
4. подготовить свой VPS;
5. установить компоненты HomeRoute;
6. настроить AmneziaWG;
7. настроить выбор маршрута через HydraRoute Neo;
8. выполнить проверку;
9. перезагрузить роутер и убедиться, что всё восстановилось автоматически.

Пошаговая инструкция находится в разделе [«Установка»](install.md).

## Если у вас Netis или другой совместимый роутер

Сначала нужен проверенный порт KeeneticOS именно для вашей модели.

HomeRoute не публикует универсальную инструкцию вида «прошить любой Netis». Разные модели отличаются загрузчиком, памятью и способом восстановления, поэтому здесь допустимы только проверенные инструкции для конкретного устройства.

После успешной установки KeeneticOS дальнейшие шаги совпадают с обычным Keenetic.

## Если HomeRoute уже настроен

Переустанавливать ничего не нужно. Для обычной проверки используйте [инструкцию по работе и диагностике](usage.md).

## Что сейчас ограничено

Автоматический установщик пока работает только в безопасном режиме просмотра плана. Реальное применение изменений будет открыто после контрольного восстановления и чистого воспроизведения.
