# Сценарии подготовки

## Native Keenetic

```text
Keenetic
→ подготовка
→ Entware/opkg
→ компоненты
→ VPS configuration
→ AWG
→ HRNeo
→ verification
→ Golden State
```

Этап перепрошивки отсутствует. Конкретные команды установки будут добавлены только после inventory и проверки чистого воспроизведения.

## Compatible non-Keenetic / Netis

```text
Device
→ проверенный KeeneticOS port
→ KeeneticOS
→ Entware/opkg
→ далее общий pipeline
```

HomeRoute не публикует непроверенные инструкции по прошивке конкретных моделей. Совместимость и процедура должны быть подтверждены отдельно до перехода к общему pipeline.
