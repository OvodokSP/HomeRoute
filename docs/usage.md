# Как пользоваться HomeRoute

После правильной настройки HomeRoute не требует ежедневного управления. Роутер сам выбирает маршрут для нужных сервисов.

## Что происходит в обычной работе

Обычный трафик продолжает идти через провайдера.

Трафик, который внесён в правила HydraRoute Neo, отправляется через отдельный интерфейс AmneziaWG на ваш VPS.

Для пользователя это выглядит как обычная домашняя сеть: на телефонах, телевизорах и компьютерах не нужно каждый раз включать отдельный VPN.

## Быстрая проверка роутера

```sh
wget -O /tmp/homeroute-doctor-router.sh \
  https://raw.githubusercontent.com/OvodokSP/HomeRoute/main/router/doctor-router.sh
chmod 700 /tmp/homeroute-doctor-router.sh
sh /tmp/homeroute-doctor-router.sh
```

В конце будет итог:

```text
HOMEROUTE_DOCTOR ... result=PASS
```

Если есть `FAIL`, не переустанавливайте систему сразу. Сначала посмотрите, какой именно пункт не прошёл.

## Быстрая проверка VPS

```sh
curl -fsSLo /tmp/homeroute-doctor-vps.sh \
  https://raw.githubusercontent.com/OvodokSP/HomeRoute/main/vps/doctor-vps.sh
chmod 700 /tmp/homeroute-doctor-vps.sh
sh /tmp/homeroute-doctor-vps.sh
```

Для конкретного развёртывания могут понадобиться параметры контейнеров и адреса клиента. Их нельзя публиковать в открытом репозитории.

## После перезагрузки роутера

В норме вручную запускать ничего не нужно. Служебные скрипты должны восстановить интерфейс AmneziaWG и правила маршрутизации автоматически.

Если нужный сервис перестал открываться после перезагрузки:

1. запустите `doctor-router.sh`;
2. проверьте, что интерфейс `opkgtun0` существует;
3. проверьте, что HydraRoute Neo работает;
4. проверьте свежий обмен данными AmneziaWG;
5. только потом переходите к ручному исправлению.

## После перезагрузки VPS

Контейнеры AWG2 и AdGuard Home должны подняться автоматически. Для проверки используйте `doctor-vps.sh`.

## Что означают основные названия

- **HydraRoute Neo** — решает, какой трафик отправлять через отдельный маршрут.
- **AmneziaWG** — защищённый канал между роутером и VPS.
- **VPS** — ваш сервер в интернете, через который выходит выбранный трафик.
- **AdGuard Home** — DNS-служба на VPS.
- **Entware** — среда дополнительных программ на роутере.

Полный список терминов есть в [словаре](terms.md).

## Что не стоит делать без необходимости

Не удаляйте вручную таблицы маршрутизации, правила firewall, служебные скрипты и интерфейс `opkgtun0`, если система работает. Перед изменениями сначала делайте диагностику и резервную копию.
