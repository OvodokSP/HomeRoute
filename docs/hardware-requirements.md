# Требования к оборудованию

Для первой версии HomeRoute не нужно искать «самый слабый роутер, на котором оно кое-как запустится». Мы используем более практичный подход: берём уже работающую конфигурацию как проверенную точку отсчёта.

## Как читать статусы

### Проверено

Эта конфигурация реально работает с HomeRoute и подтверждена диагностикой.

### Ожидаемо совместимо

Ресурсов не меньше, чем у проверенной конфигурации, и нужная программная среда доступна. Это хороший кандидат, но на конкретной модели ещё не выполнен полный тест HomeRoute.

### Не проверено

Данных недостаточно. Это **не означает**, что устройство не подойдёт.

### Не подходит

Есть подтверждённая причина, из-за которой HomeRoute на этой конфигурации не может работать.

## Проверенный роутер

Текущая рабочая конфигурация:

| Параметр | Значение |
|---|---|
| Устройство | Netis N6 v1 AX1800 |
| Прошивка | совместимый порт KeeneticOS |
| Процессор | MediaTek MT7621AT, MIPS, класс 880 МГц |
| Оперативная память | 256 МБ |
| Flash | 128 МБ NAND |
| Entware | работает |
| HomeRoute | проверен |

Для первой версии разумно ориентироваться минимум на этот уровень.

Устройство считается **ожидаемо совместимым**, если:

- оперативной памяти не меньше 256 МБ;
- постоянной памяти не меньше 128 МБ либо есть отдельное достаточное хранилище для Entware;
- работает KeeneticOS или проверенный порт KeeneticOS;
- доступен Entware;
- для архитектуры существуют необходимые пакеты AmneziaWG и HydraRoute Neo.

Если памяти меньше, устройство не объявляется неподходящим — оно просто остаётся непроверенным.

## Что лучше брать при покупке нового роутера

Чтобы оставить запас под обновления и дополнительные компоненты:

- 512 МБ RAM или больше;
- 128 МБ flash минимум, лучше 256 МБ и больше;
- современный многоядерный процессор;
- официальный Keenetic с поддержкой OPKG предпочтительнее стороннего роутера с портированной KeeneticOS, если цена и возможности сопоставимы.

Больше памяти и более быстрый процессор не гарантируют совместимость сами по себе: важна поддержка KeeneticOS, Entware и нужных пакетов.

## Проверенный VPS

Текущий HomeRoute работает на VPS со следующими параметрами:

| Параметр | Значение |
|---|---|
| vCPU | 1 |
| RAM | около 1,9 ГБ |
| Диск | 30 ГБ |
| ОС | Ubuntu 26.04 LTS |
| Контейнеры | Docker + AWG2 + AdGuard Home |

Для первой версии сервер с такими же или большими ресурсами и совместимой Linux-средой считается ожидаемо подходящим.

Сервер слабее этой конфигурации может работать, но пока не проверен.

## Что выбрать без лишних раздумий

Если покупаете роутер специально под HomeRoute, ориентируйтесь на **512 МБ RAM или больше** и официальную поддержку KeeneticOS/OPKG.

Если арендуете VPS специально под HomeRoute, безопасная отправная точка — **1 vCPU, 2 ГБ RAM и 30 ГБ диска**.

Список конкретных моделей находится в [матрице совместимости](compatibility-matrix.md).
