# Матрица совместимости

Матрица отделяет фактическую проверку от ожиданий. В первой версии HomeRoute текущий рабочий Golden State принят как `Verified baseline`; устройства с равными или большими ресурсами могут получить `Expected`, если их программная среда совместима.

Пул моделей, для которых собраны публичные аппаратные/upstream-данные, ведётся отдельно в [`router-candidates.md`](router-candidates.md).

| Производитель | Модель | Тип | KeeneticOS | Entware | HomeRoute | Статус проверки | Примечание |
|---|---|---|---|---|---|---|---|
| Netis | N6 v1 AX1800 | Compatible device / KeeneticOS port | Да, port | Да | `Verified baseline` | Фактический Golden State | Reference-router: MT7621AT/MIPS 880 MHz class, 256 MB RAM, 128 MB NAND; текущая рабочая конфигурация HomeRoute |

## Тип устройства

Допустимые значения:

- `Native Keenetic` — устройство, для которого KeeneticOS является штатной платформой;
- `Compatible device / KeeneticOS port` — стороннее устройство с отдельно проверяемым портом KeeneticOS.

## HomeRoute status

- `Unknown` — данных недостаточно даже для обоснованного ожидания;
- `Not validated` — один или несколько параметров ниже supported floor либо ещё не доказана совместимость существенной части программной среды;
- `Not suitable` — несовместимость подтверждена воспроизводимым наблюдением;
- `Expected` — ресурсы не ниже verified baseline и документарно подтверждена необходимая программная среда, но полного теста HomeRoute на конкретной модели ещё не было;
- `Verified baseline` — текущая рабочая reference-конфигурация, от которой строится supported floor;
- `Verified` — HomeRoute фактически воспроизведён на другой указанной модели/конфигурации с записанным evidence.

`Expected` нельзя представлять пользователю как доказанную совместимость. `Not validated` нельзя автоматически трактовать как несовместимость.

## Правило baseline

Reference-router задаёт текущую доказанную границу для первой версии:

- 256 MB RAM;
- 128 MB NAND/flash class;
- MT7621AT/MIPS 880 MHz CPU class как фактически работающая точка;
- рабочий KeeneticOS + Entware/OPKG;
- доступность обязательных HomeRoute/AWG2/HRNeo-side компонентов.

Для количественных ресурсов действует правило: равное или большее значение не ухудшает статус **только при сохранении совместимой программной платформы**. CPU разных архитектур нельзя сравнивать только по MHz.

## Правила заполнения

Для `Expected`, `Verified baseline`, `Verified` и `Not suitable` должна существовать проверяемая основа статуса: текущий Golden State, inventory, upstream-документация, тестовый протокол или иной воспроизводимый результат.

Для устройств с KeeneticOS port совместимость самого порта и совместимость HomeRoute остаются разными проверками. После clean reproduction строка `Expected` может быть повышена до `Verified`.
