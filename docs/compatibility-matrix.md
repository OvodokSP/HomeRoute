# Совместимость роутеров

Здесь собраны модели, для которых есть хотя бы часть проверяемых данных.

Важно: «ожидаемо совместимо» и «проверено» — не одно и то же.

## Что означают статусы

- **Проверено** — HomeRoute реально запускался на этой модели и прошёл проверку.
- **Ожидаемо совместимо** — характеристики и программная среда подходят, но полного запуска HomeRoute на этой модели ещё не было.
- **Не проверено** — данных недостаточно.
- **Не подходит** — несовместимость подтверждена.

## Проверенная опорная модель

| Производитель | Модель | KeeneticOS | Entware | Статус | Комментарий |
|---|---|---|---|---|---|
| Netis | N6 v1 AX1800 | порт KeeneticOS | Да | **Проверено** | MT7621AT, 256 МБ RAM, 128 МБ NAND; текущая рабочая конфигурация HomeRoute |

## Как оцениваются остальные модели

Для статуса «ожидаемо совместимо» одновременно нужны:

1. не меньше 256 МБ RAM;
2. достаточное хранилище для Entware;
3. рабочий KeeneticOS или проверенный порт;
4. Entware/OPKG;
5. доступные пакеты AmneziaWG и HydraRoute Neo для нужной архитектуры.

Более мощный процессор или больший объём памяти сами по себе не дают статус совместимости.

Список моделей-кандидатов с собранными характеристиками находится в [отдельной таблице](router-candidates.md).

## Родной Keenetic и сторонний роутер

**Родной Keenetic** — модель, для которой KeeneticOS является штатной системой. Это самый простой вариант для пользователя.

**Сторонний роутер с портом KeeneticOS** — например, некоторые Netis, Xiaomi, Cudy и другие модели. Для них отдельно должна быть подтверждена работоспособность самого порта прошивки.

Совместимость порта KeeneticOS и совместимость HomeRoute — это две разные проверки.

## Почему в таблице мало строк со статусом «Проверено»

HomeRoute специально не превращает характеристики на бумаге в обещание работоспособности. Новая модель получит статус «Проверено» только после реального развёртывания и проверки после перезагрузки.

Это медленнее, зато пользователь видит разницу между фактом и предположением.
