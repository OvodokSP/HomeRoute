# Общие требования

HomeRoute не требует от пользователя разбираться в процессорах, таблицах маршрутов и результатах тестов производительности. Для выбора оборудования достаточно нескольких понятных условий.

## Роутер

Нужен роутер, на котором:

- работает KeeneticOS;
- можно использовать Entware;
- хватает памяти и места для компонентов HomeRoute;
- поддерживается нужная архитектура пакетов.

Текущая рабочая конфигурация считается проверенной опорной точкой. Устройства с меньшими ресурсами не объявляются нерабочими — они просто пока не проверены. Устройства с такими же или большими ресурсами и совместимой программной средой считаются ожидаемо совместимыми, пока не пройдут реальную проверку.

Конкретные значения и примеры моделей находятся в [требованиях к оборудованию](hardware-requirements.md).

## VPS

Для каждого развёртывания нужен отдельный VPS под управлением пользователя.

Проверенная конфигурация проекта работает на сервере с 1 vCPU, примерно 2 ГБ RAM и 30 ГБ диска. Это проверенная опорная конфигурация, а не утверждение о физическом минимуме.

## Программная среда

В текущей версии используются:

- KeeneticOS;
- Entware;
- HydraRoute Neo;
- AmneziaWG 2.x;
- Docker на VPS;
- AdGuard Home на VPS.

`nfqws` — необязательный дополнительный компонент. `tg-ws-proxy` — резервный канал.

AmneziaWG 3.x пока не входит в проверенную конфигурацию HomeRoute.

## Прошивка совместимых роутеров

Для обычного Keenetic перепрошивка не требуется.

Для Netis и других совместимых устройств может понадобиться порт KeeneticOS. HomeRoute будет публиковать только те модели и способы установки, для которых есть проверяемые данные.
