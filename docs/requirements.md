# Требования

## Принцип классификации

Пользователь не должен самостоятельно проходить benchmarking. После hardware/package inventory устройства будут распределяться по трём понятным классам:

1. **Не подходит.**
2. **Достаточно для работы.**
3. **Рекомендуется / есть запас.**

Отдельно будет опубликован перечень проверенных и совместимых моделей. Точные минимальные значения CPU, RAM и storage до завершения preflight/inventory не устанавливаются.

## Среда

- Для native Keenetic этап перепрошивки отсутствует.
- Для совместимых устройств семейства Netis может потребоваться заранее проверенный KeeneticOS port.
- Непроверенные инструкции по прошивке конкретных моделей не публикуются.
- После KeeneticOS используется Entware/opkg.
- Для каждого развёртывания обязателен отдельный рабочий VPS пользователя.
- Reference baseline — AmneziaWG 2.x; AWG 3.x не является текущим требованием.
