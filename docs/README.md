## Если что-то не работает

Сначала используйте [ЧаВо](faq.md), затем [инструкцию по диагностике](usage.md).

Не начинайте с удаления маршрутов, переустановки пакетов или сброса роутера: большая часть проверок HomeRoute специально сделана без изменения системы.
