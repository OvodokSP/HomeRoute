# HomeRoute

[English version](docs/README_EN.md)

HomeRoute — воспроизводимая методика построения и восстановления домашней сетевой инфраструктуры. Проект объединяет документацию, диагностику и автоматизацию существующих решений; он не реализует собственный VPN или технологию обхода DPI и не заменяет upstream-проекты.

## Для чего это нужно

Материалы HomeRoute должны помочь:

- повторить конфигурацию после замены роутера;
- восстановить её после новой прошивки;
- перенести схему в другой дом;
- развернуть аналогичную систему на другом совместимом оборудовании;
- использовать отдельный VPS, принадлежащий конкретному пользователю.

## Архитектура верхнего уровня

Проверенный маршрут Telegram в **HomeRoute Golden State v0.1**:

```text
LAN client → HRNeo → ipset opkgtun0 → CONNMARK 0x3001
→ ip rule → routing table 301 → default dev opkgtun0
→ AmneziaWG 2.x → VPS → AWG2 → Internet
```

HRNeo управляет выборочной маршрутизацией, `opkgtun0` служит выделенным AWG-интерфейсом, а пользовательский VPS завершает туннель. `nfqws` остаётся самостоятельным необязательным слоем, `tg-ws-proxy` — резервным каналом.

## Состояние v0.1

Golden State подтверждён после перезагрузки Keenetic и полного reboot VPS. Проверены восстановление AWG2, выборочная маршрутизация HRNeo, таблица `301`, mark `0x3001`, NAT/FORWARD, DNS redirect TCP/UDP 53 и удаление legacy-конфигурации.

Пока **не автоматизированы и не подтверждены** установка на чистое устройство, определение аппаратных требований и полноценные router/VPS installers. Текущие install-скрипты — безопасные PRE-ALPHA заглушки. AWG 3.x не входит в baseline.
