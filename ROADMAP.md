# План развития

- **Phase 0 — Reference State:** зафиксировать проверенный Golden State. Выполнено для v0.1.
- **Phase 1 — Inventory & Requirements:** собрать hardware/package inventory и определить проверяемые требования.
- **Phase 2 — Router Installer:** создать и проверить безопасную автоматизацию роутера.
- **Phase 3 — VPS Installer:** создать и проверить автоматизацию VPS.
- **Phase 4 — Doctor / Backup / Restore:** развить диагностику и безопасные процедуры резервирования и восстановления.
- **Phase 5 — Clean Device Reproduction:** воспроизвести состояние на чистом устройстве.
- **Phase 6 — Compatibility Matrix:** опубликовать проверенные модели и понятные классы пригодности.
- **Future — validated AWG 3.x migration:** рассматривать миграцию только после появления и проверки совместимой реализации для целевого роутера/KeeneticOS.
