# Reproduction workspace

This directory defines the **local-only** inputs used by the first clean-device reproduction (HL-502).

The repository contains only public schemas, examples and tooling. Real deployment inputs must stay outside Git or under ignored `reproduction/local/`.

## Boundary

A router reproduction bundle may contain:

- exact persistence hooks captured from a verified reference or generated by an approved renderer;
- the local AWG configuration for `opkgtun0`;
- mutable HRNeo files: `hrneo.conf`, `domain.conf`, `ip.list`;
- exact local package artifacts required by the reproduction;
- a generated manifest containing only file paths, sizes and checksums.

The bundle manifest is safe to inspect, but the bundle files themselves may contain private keys, peer material, endpoints or user-specific routing lists and **must not be committed**.

## Current deterministic boundary

Already deterministic:

- HRNeo `3.18.3-1` exact artifact identity;
- reference hook identities/hashes;
- router package versions;
- AWG/runtime/routing invariants;
- live backup/rollback behavior.

Still unresolved before a fully deterministic router reproduction apply:

- exact Chur/AWG package artifacts are not yet pinned by content hash;
- exact hook source must be supplied as a verified local bundle or replaced by a separately reviewed deterministic renderer;
- the two Telegram NDM hooks still contain unresolved `/opt/...` dependency targets at the semantic level.

The tooling must report these as explicit blockers. It must never synthesize missing source or silently fall back to mutable online packages.
